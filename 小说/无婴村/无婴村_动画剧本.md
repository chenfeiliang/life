### 角色卡片使用说明
每个角色包含以下维度：

- **外貌特征**：体型、面部、发型、服饰、疤痕/印记

### 👵 赵老妇 —— "被母爱吞噬的老人"

| 维度 | 详细内容 |
|------|----------|
| **姓名** | 赵张氏（村民叫她"赵老妇"或"赵婶子"） |
| **年龄** | 72 岁（出生于 1954 年，生于战乱年代） |
| **性别** | 女 |
| **身份** | 村民，丧子寡妇，单亲祖母 |
| **家庭** | 丈夫早逝（病逝），儿子赵大强已死（疑似车祸），孙子是唯一的精神支柱 |
| **身高** | 152cm（因驼背实际视觉更矮） |
| **体重** | 42kg（极度消瘦） |
| **体型** | 佝偻如虾米，脊椎弯曲成 C 形，双腿因风湿变形 |

#### 🖼️ **外貌特征**

**面部：**
- 皮肤：枯黄如陈年宣纸，布满老年斑和皱纹
- 眼睛：深陷眼窝，眼球浑浊发黄，瞳孔放大反应迟钝，血丝密布
- 眉毛：花白稀疏，眉头常年紧锁
- 鼻子：塌陷萎缩，鼻孔外露，吸气时有呼哧声
- 嘴巴：嘴唇干裂起皮，嘴角下垂呈倒八字
- 牙齿：只剩几颗残根，说话漏风
- 特殊印记：右脸颊有一块暗红色胎记（从出生就有，她总用头发遮住）

**发型：**
- 白发全部梳成髻，用一根木簪固定
- 鬓角和头顶有碎发凌乱翘起
- 发质干枯如草，打结严重

**服饰：**
- 上衣：褪色的蓝布褂子，补丁叠补丁，领口油渍明显
- 裤子：黑色粗布裤，裤脚沾满泥点
- 鞋：手工纳底布鞋，鞋底磨穿了一半
- 配饰：右手腕戴一串佛珠（珠子已经发黑）；腰间系围裙（洗得发白）
- 随身物品：一块染黑水的旧蓝布包，一把生锈的剪刀

**手部：**
- 手指关节肿大变形，指甲厚而黄，缝衣时总是抖
- 手背青筋暴突，血管清晰可见
- 掌心布满老茧和裂口

**步态：**
- 走路拖沓，左脚轻微跛行
- 弯腰驼背，重心前倾
- 遇到激动时会突然加快脚步，像要摔倒又站稳

#### 💭 **性格特点**

**主导性格：固执母性**
- 对孙子爱到极致，可以牺牲一切
- 坚信孙子还活着，拒绝接受现实
- 对外界警告充耳不闻，我行我素

**次级性格：神经脆弱**
- 容易受到刺激，情绪波动剧烈
- 独处时会自言自语，幻觉频发
- 害怕黑夜，但又喜欢在夜晚活动

**性格缺陷：**
- **偏执妄想**：坚信孙子在水底等她，每天对着湖面说话
- **认知失调**：明知死了孩子，但心理上拒绝接受
- **社交退缩**：几乎不与村民交流，只在必要时露面
- **自我惩罚**：故意穿破衣烂衫，认为这是赎罪

**隐藏的温柔：**
- 虽然精神失常，但对小动物从不伤害
- 会把捡到的食物留给流浪猫狗
- 偶尔会对路过的陌生人露出微笑

#### 📖 **背景故事**

**早年（1954-1980）：**
- 出生于贫苦农家，16 岁嫁给同村的赵大勇
- 婚后三年生下儿子赵大强，从此视若珍宝
- 丈夫在工地事故中去世（1982 年），独自抚养儿子长大
- 靠做针线活、帮人洗衣勉强维持生计

**中年（1980-2010）：**
- 儿子结婚，媳妇是邻村嫁过来的，贤惠但体弱
- 孙子出生那年是丰收年，她熬了七个七夜的夜给孩子缝新衣
- 媳妇生产后不久病故（难产并发症）
- 从此她一个人带孙子，祖孙相依为命

**晚年（2010-2026）：**
- 村里开始出现死婴现象，她的孙子是最后一个
- 孙子死在她怀里的那一刻，她感觉自己的灵魂也被带走了
- 从此变得神神叨叨，整天念叨"孙孙还没冷""给他穿衣服就好了"
- 被村民同情但疏远，因为她"不正常"

**关键事件：**
1. **丧妻之痛**（58 岁）：妻子病逝，失去唯一依靠
2. **隔代育儿**（58-60 岁）：独自抚养孙子，感情极深
3. **孙子夭折**（60 岁）：亲手把孙子放进河里，这是他第一次崩溃
4. **地窖藏怪**（60-61 岁）：偷偷养着怪物孙子，是她唯一的慰藉

#### 🔄 **行为习惯**

**日常小动作：**
1. 说话时无意识地搓弄蓝布包的边角
2. 听到婴儿哭声会猛地抬头，四处张望
3. 下雨天会躲在屋檐下听雨声，像在听水波
4. 看到红衣服的小孩会盯着看很久，眼眶发红
5. 晚上睡不着时就坐在地窖门口，拿着油灯发呆

**口头禅：**
- "孙孙别怕，奶奶在这儿。"
- "他们不懂，俺们是活着的。"
- "这世道太黑了，只有水里亮堂。"
- "乖孙慢点走...奶奶看着你..."

**标志性物件：**
- **蓝布包**：装着孙子的遗物（红棉袄碎片），每天擦拭三次
- **油灯**：家里唯一的照明工具，她说"光能照着路"
- **佛珠**：念珠，但从不念佛，只是数珠子

#### 🎤 **声音特质**

**音色：** 沙哑粗糙，像砂纸摩擦木头
**语速：** 平时很慢，激动时会突然变快，像连珠炮
**音调：** 低沉为主，哭喊时会尖利刺耳
**呼吸：** 经常喘不上气，说完一句要停顿好几秒
**方言：** 浓重的乡土口音，用词古旧（"孙孙""俺""咋办"）

**典型声线示例：**
- **平静时**："孙孙啊...奶奶给你洗衣服呢..."（轻柔颤抖）
- **激动时**："他没死！他没死！我看见他了！"（嘶吼破音）
- **悲伤时**："要是他活着，今年就该五岁了..."（哽咽断断续续）
- **满足时**："没事的，奶奶养着你..."（温柔如哄睡）

#### 📈 **情感弧线**

```
第一幕：绝望麻木
- 开场时整个人像一具空壳
- 眼神空洞，说话没有起伏
- 观众感觉她已经放弃希望

第二幕：疯狂复苏
- 得知怪物可能是孙子后，突然爆发出生命力
- 不顾一切冲出去，眼中重新有了光
- 这是她多年来第一次主动出击

第三幕：崩溃边缘
- 湖边见到怪物时，既欣喜又恐惧
- 被推开后陷入半昏迷状态
- 意识到怪物真的不认识她了

第四幕：黑暗觉醒
- 地窖中发现真正的怪物孙子
- 选择接受这个事实，甚至为此自豪
- 眼神从迷茫变为坚定
- 最后坐在黑暗中守护孙子，是一种悲壮的胜利
```

#### 🎬 **表演提示**

**哭泣场景：**
- 不要嚎啕大哭，而是无声流泪
- 眼泪顺着皱纹流进嘴里，她会舔一下
- 肩膀微微耸动，但不发出声音
- 最后一刻才会抽泣起来

**愤怒场景：**
- 不是拍桌子骂人，而是身体发抖
- 眼睛瞪圆，瞳孔收缩
- 说话语速加快，字字如刀
- 双手紧紧攥着什么东西（蓝布包/剪刀）

**温柔场景：**
- 身体前倾，姿态放低
- 声音放轻到几乎听不见
- 手指轻轻抚摸着物体（像摸孩子的头）
- 脸上露出一种混合了痛苦和满足的微笑

**幻觉场景：**
- 眼神聚焦在某处虚空
- 转头跟不存在的人对话
- 听到不存在的婴儿啼哭
- 嘴角上扬（她在笑，观众不知道她在跟谁笑）

### 👴 赵老大 —— "孝道压垮的儿子"

| 维度 | 详细内容 |

| **家庭** | 母亲赵老妇健在，妻子三年前因病去世，没有孩子 |
| **身高** | 170cm |
| **体重** | 68kg（精瘦结实） |

#### 🖼️ **外貌特征**

**面部：**
- 皮肤：黝黑粗糙，晒出深刻皱纹
- 眼睛：深陷，目光常年在忧虑和疲惫之间游移
- 眉毛：浓黑，眉峰高耸，显出倔强
- 鼻子：扁平宽大，鼻翼因常年抽烟熏黄
- 嘴巴：紧闭时呈直线，笑起来有单边酒窝
- 胡须：下巴和上唇总有短须茬，刮得不干净

**发型：**
- 短发，平头样式，头发硬直
- 鬓角有白发夹杂其中
- 夏天汗湿后会贴在前额

**服饰：**
- 上衣：灰色中山装款式外套，袖口磨损
- 内衬：蓝色汗衫，领口泛黄
- 裤子：黑色长裤，膝盖处打了补丁
- 鞋：黑色解放鞋，鞋底开胶一半
- 配饰：腰间挂烟袋锅，口袋里总揣着手帕

**手部：**
- 手掌宽大，指节粗大
- 指纹因常年劳作模糊不清
- 左臂有三道爪痕（围湖时被怪物抓伤），颜色发白

**体态：**
- 站立时习惯侧身，保护受伤的那条腿
- 走路有些跛，左腿发力不足
- 拿东西时习惯用右手，左手总是微微蜷缩

#### 💭 **性格特点**

**主导性格：孝顺隐忍**
- 对母亲言听计从，哪怕不合理也要照做
- 承受压力时不抱怨，默默忍耐
- 把母亲的幸福当作自己人生的首要任务

**次级性格：懦弱无能**
- 面对冲突时选择退让
- 不敢直接表达反对意见
- 总是说"妈你说得对""我再想想办法"

**性格缺陷：**
- **过度依赖**：生活毫无主见，凡事问母亲
- **逃避责任**：遇到困难就躲，不愿正面解决
- **自我否定**：认为自己没用，配不上好日子
- **情感压抑**：内心痛苦但从不说出来

**隐藏的优点：**
- 非常勤劳，从不偷懒
- 对别人慷慨大方，对自己吝啬抠门
- 关键时刻会爆发勇气（比如护母时）
- 记忆力极好，记得村里每件事

#### 📖 **背景故事**

**早年（1979-1995）：**
- 从小跟着母亲长大，父亲早逝
- 16 岁辍学务农，照顾母亲起居
- 20 岁相亲娶了媳妇，日子还算安稳

**中年（1995-2023）：**
- 媳妇怀孕两次都流产，医生说是体质问题
- 第三次怀孕顺利生下儿子，全家欢喜
- 但孙子出生后也是死婴，媳妇因此抑郁自杀
- 从此他变成"克家人"的命，不敢再提生孩子

**晚年（2023-2026）：**
- 一个人带着疯癫的母亲生活
- 白天干活赚钱，晚上哄母亲睡觉
- 村里人背后说他可怜，当面又避开他
- 这次围湖行动是他第一次主动站出来

**关键事件：**
1. **丧妻之痛**（42 岁）：媳妇自杀，他找到时已经凉了
2. **孙子夭折**（44 岁）：亲手送孙子水葬，一夜白头
3. **精神崩溃边缘**（44-46 岁）：多次想自杀但舍不得母亲
4. **围湖受伤**（47 岁）：为了保护村民和母亲，拼尽全力

1. 思考时用拇指搓食指关节
2. 紧张时不停摸左边口袋（那是他的手帕）
3. 看到母亲情绪不对就会低头不说话
4. 吃饭时把肉夹给母亲，自己只吃菜
5. 晚上睡觉前要检查门窗是否关好

**口头禅：**
- "妈，你别这样说..."
- "我知道了，我去办。"
- "没事的，过两天就好了。"

**标志性物件：**

- **烟袋锅**：旱烟，压力大时猛吸
- **柴刀**：挂在墙上，既是工具也是防身武器

#### 🎤 **声音特质**

**音色：** 中等偏低，带点沙哑（常年抽烟）
**语速：** 缓慢稳重，说话有条理
**音调：** 温和，很少提高音量
**呼吸：** 平稳，但在紧张时会有短暂屏息
**方言：** 当地土话，但发音比较标准

**典型声线示例：**
- **安慰母亲**："妈，我知道你难受...我也一样..."（低沉共情）

- **痛苦时刻**："为什么偏偏是我们家..."（压抑的哽咽）
- **爆发瞬间**："你别说了！都是为了你好！"（罕见的大声）

1. **眼神永远是核心**：要表现出那种介于清醒和疯癫之间的状态
2. **声音要层次分明**：平时低哑颤抖，激动时尖利刺耳，温柔时几乎无声
3. **肢体语言要有记忆点**：比如永远攥着蓝布包，走路时左脚拖地
4. **关键情绪转换要突兀**：从安静到尖叫可以在一秒内完成

### 赵老大的表演要点
1. **内敛是关键**：他的痛苦是无声的，所有的压抑都体现在细微动作上
2. **眼神要传达矛盾**：既想反抗又想顺从的拉扯感
3. **身体要体现负担**：弯腰驼背的感觉要贯穿始终，即使在最痛苦的时候

### 所有角色的共同要求
1. **真实性**：不要演"老人"演"这个人"，不要演"村民"演"这个角色"
2. **层次性**：每个人都不能是单维度的，要有复杂性
3. **连贯性**：情感弧线要清晰，每一场戏都是上一场的延续和下一场的铺垫
4. **互动性**：角色之间的关系要通过眼神、语气、肢体语言体现出来
